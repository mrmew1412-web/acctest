เพิ่มเอกสาร
🔗 วิธีเชื่อมต่อ Google Sheets + Drive + GitHub
ระบบนี้ใช้ Google Sheets API เป็นฐานข้อมูล, Google Drive สำหรับเก็บไฟล์ และ GitHub สำหรับ backup ข้อมูล JSON ทั้งหมด
1
สร้าง Google Cloud Project
ไปที่ console.cloud.google.com ↗
เปิดใช้ Google Sheets API และ Google Drive API
สร้าง Service Account → ดาวน์โหลด JSON Key
2
สร้าง Google Spreadsheet
สร้าง Spreadsheet ใหม่ใน Google Drive
Share ให้กับ Service Account email (Editor)
Copy Spreadsheet ID จาก URL (หลัง /d/ ก่อน /edit)
3
GitHub Repository
สร้าง repository ใหม่ (private แนะนำ)
ไปที่ Settings → Developer settings → Personal access tokens
สร้าง token ที่มี repo scope
4
กรอกข้อมูลในหน้า ⚙️ ตั้งค่า
กรอก Spreadsheet ID, API Key, GitHub Token, Repository
เปิด toggle การเชื่อมต่อที่ต้องการใช้งาน
✅ ข้อมูลทั้งหมดเก็บใน localStorage ของเบราว์เซอร์ก่อน จากนั้น sync ไป Google Sheets และ backup ไป GitHub อัตโนมัติเมื่อบันทึกเอกสาร
